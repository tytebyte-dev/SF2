# SF2 — поиск повторов и похожих фото на Android

Приложение находит в галерее телефона дубликаты и очень похожие картинки (например, арты) **полностью офлайн**:
у приложения нет разрешения `INTERNET`, никакие фото никуда не отправляются.

## Как оно бережёт вашу галерею

- **Поиск только читает файлы.** Пока вы сами ничего не отметили, ничего не меняется.
- **Ничего не отмечено заранее.** Кнопка «Предложить выбор» лишь подсказывает, что убрать (всё, кроме лучшего по качеству).
- **В каждой группе всегда остаётся хотя бы одно фото** — отметить все копии нельзя.
- **Два подтверждения:** диалог приложения (с галочкой «я посмотрел(а)» и списком файлов) и затем системный диалог Android.
- **Только корзина, не удаление.** Используется `MediaStore.createTrashRequest`: файлы уходят в системную корзину и восстанавливаются из неё (обычно ~30 дней).
- После перемещения приложение проверяет, что файлы действительно ушли, и сообщает о расхождениях.
- Операции выполняются по одной группе за раз, чтобы ошибка не затронула много файлов.
- Кнопка «Это не дубликаты» скрывает группу (запоминается на устройстве).

## Как ищутся дубликаты (минимум ошибок)

1. **Точные копии:** SHA-256 содержимого (считается только для файлов с одинаковым размером).
2. **Похожие:** из уменьшенной копии каждой картинки считаются pHash (DCT), dHash, цветовая раскладка 4×4 и корреляция яркости 16×16.
   Пара считается повтором, только если проходит **все** проверки сразу, плюс совпадает форма кадра.
3. **Полная связность в группах:** фото попадает в группу, только если похоже на *каждого* её участника, а не на одного
   (цепочка «A~B, B~C» не склеит разные картинки).
4. Три режима точности — «Строго», «Сбалансированно», «Широко»; меняются после проверки без повторного сканирования.

Ограничения: повёрнутые или отзеркаленные копии, а также сильно обрезанные версии не считаются повторами.

## Сборка

Сборка идёт в GitHub Actions (`.github/workflows/build.yml`): тесты движка, debug- и release-APK.
APK лежит в артефакте запуска (Actions → нужный запуск → `SF2-apk`). При создании тега `vX.Y.Z` APK прикрепляется к релизу.

Подпись — ключ `sf2-debug.keystore` из репозитория (пароль `android`), чтобы новые сборки ставились поверх старых.
Это ключ для личного использования; для публикации в магазине создайте собственный.

Локально: `gradle assembleDebug` (JDK 17, Android SDK 34).

Требования: Android 11 (API 30) и новее.
